## 연습 루틴 (문장 1개당 2~3분)
1. H: 문장 숨기고 듣기 → 2. L: 보면서 3번 반복 (어려우면 2키=0.75x)
3. R: 따라 말하기 녹음 → 빨간 단어 클릭해서 확인 → C: 원문 → 내 목소리 비교
4. S: 이어폰 끼고 원문과 동시에 쉐도잉

## 단축키
Space 원문 듣기 / L 반복 / 1·2·3 속도 0.5·0.75·1x / H 문장 숨김 / K 한국어 뜻
R 녹음 / S 쉐도잉 / P 내 목소리 / C 원문→나 비교 / ←→ 이전·다음

## 참고
- 문장 263개, 영어 자동자막 기반 + 명백한 오인식 교정(Bauhaus, Villa Savoye, ligatures 등), 한국어 뜻은 직접 번역
- 구간 시간은 자막에서 추정한 값이라 몇백 ms 어긋날 수 있음 → "구간 보정 ±" 버튼 (문장별 저장)
- 점수 = 음성 인식이 알아들은 단어 비율(명료도). 억양·강세는 C 비교로 귀로 확인
- 기록은 브라우저 localStorage에 저장됨

## 일본어 버전 메모
- 일본어 자막은 영상 제작자가 직접 단 자막 기반, 후리가나와 한국어 뜻은 직접 작성(유튜브 한국어 자막은 기계번역이라 사용 안 함)
- 채점: 음성 인식 결과를 한자 표기·히라가나 읽기·자주 쓰는 다른 표기(예: みがきました/磨きました) 모두 정답으로 인정. (괄호)는 선택
- F: 후리가나 켜고 끄기 / H: 문장과 영상(화면에 박힌 자막) 함께 가리기
